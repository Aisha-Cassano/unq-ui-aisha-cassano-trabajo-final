# TFI de Interfaces de Usuario 2026

## Info básica del juego "Palabras Encadenadas":
<p> Descripción: Es un juego web por tiempo hecho con React y Vite con sistema de puntaje, donde el usuario debera ingresar una palabra inicial luego, para ingresar otra palabra, esta debe iniciar con la misma letra que la ultima letra de la palabra anterior.</p>


## Requisitos previos
- [Node.js](https://nodejs.org/) versión 18 o superior (incluye `npm`).
- Conexión a internet, ya que el juego valida las palabras contra una API externa.


## Instalación

1. Clonar el repositorio:
```bash
   git clone <https://github.com/Aisha-Cassano/unq-ui-aisha-cassano-trabajo-final.git>
```

2. Entrar a la carpeta del proyecto:
```bash
   cd Palabras-Encadenadas
```

3. Instalar las dependencias:
```bash
   npm install
```

## Ejecución
Para levantar el proyecto en modo developer:
```bash
npm run dev
```

La terminal va a mostrar una URL local (normalmente `http://localhost:5173`). Abrír esa dirección en el navegador para ir al menú principal de la app.


## Tecnologías utilizadas

- JavaScript
- CSS
